# SimpleFlow - API Configuration Examples

Complete configuration examples for all node types.

## 🤖 AI Service Nodes

### Gemini AI

**Basic Text Generation:**
```json
{
  "prompt": "Write a professional email about: {{input}}",
  "model": "gemini-pro",
  "temperature": 0.7,
  "max_tokens": 1024
}
```

**Data Analysis:**
```json
{
  "prompt": "Analyze this data and provide 3 key insights:\n{{input}}",
  "model": "gemini-pro",
  "temperature": 0.5,
  "max_tokens": 2000
}
```

**Creative Writing:**
```json
{
  "prompt": "Write a creative story based on: {{input}}",
  "model": "gemini-pro",
  "temperature": 0.9,
  "max_tokens": 3000
}
```

**Available Models:**
- `gemini-pro`: General purpose
- `gemini-pro-vision`: With image support (future)

```json
{
  "prompt": "Summarize this in 3 bullet points:\n{{input}}",
```

## 📊 Google Sheets Nodes

### Read Data

**Read Entire Sheet:**
```json
{
  "spreadsheet_id": "1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms",
  "range": "Sheet1!A1:Z1000"
}
```

**Read Specific Range:**
```json
{
  "spreadsheet_id": "your-spreadsheet-id",
  "range": "Sales!A2:D100"
}
```

**Read Multiple Columns:**
```json
{
  "spreadsheet_id": "your-spreadsheet-id",
  "range": "Data!A:A,C:C,E:E"
}
```

### Write Data

**Write Single Cell:**
```json
{
  "spreadsheet_id": "your-spreadsheet-id",
  "range": "Sheet1!A1",
  "values": [["Generated by SimpleFlow"]]
}
```

**Write Row:**
```json
{
  "spreadsheet_id": "your-spreadsheet-id",
  "range": "Sheet1!A2",
  "values": [["Name", "Email", "Status"]]
}
```

**Write Multiple Rows:**
```json
{
  "spreadsheet_id": "your-spreadsheet-id",
  "range": "Sheet1!A1"
}
```
*Note: values will come from {{input}}*

## 💬 WhatsApp Nodes

### Send Text Message

**Simple Message:**
```json
{
  "to": "6281234567890",
  "message": "Hello from SimpleFlow!"
}
```

**With Dynamic Content:**
```json
{
  "to": "6281234567890",
  "message": "Your report is ready:\n\n{{input}}"
}
```

**Multiple Recipients (send separately):**
```json
{
  "to": "6281234567890",
  "message": "Status update: {{input.status}}"
}
```

**Phone Number Format:**
- Include country code
- No + or spaces
- Example: 6281234567890 (Indonesia)
- Example: 1234567890 (USA: 11234567890)

### Send Template Message

```json
{
  "to": "6281234567890",
  "template_name": "hello_world",
  "language_code": "en_US",
  "parameters": ["John", "Doe"]
}
```

## 🎯 Best Practices

### 1. Use Descriptive Prompts
```json
// Good
{
  "prompt": "Analyze the following sales data and provide:\n1. Total revenue\n2. Top product\n3. Growth rate\n\nData: {{input}}"
}

// Bad
{
  "prompt": "{{input}}"
}
```

### 2. Set Appropriate Temperature
- **0.0 - 0.3**: Factual, consistent (reports, data)
- **0.4 - 0.7**: Balanced (general use)
- **0.8 - 1.0**: Creative (stories, ideas)

### 3. Specify Max Tokens
- Short responses: 100-500 tokens
- Medium: 500-1500 tokens
- Long: 1500-4000 tokens

### 4. Use Placeholders Effectively
```json
{
  "message": "Hello {{name}}!\n\nYour order {{order_id}} is ready.\n\nTotal: ${{total}}"
}
```

### 5. Error Handling
Always test nodes individually before chaining!
